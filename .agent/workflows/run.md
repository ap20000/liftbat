description: How to run the Flutter application
---

To run the application, follow these steps:

1. **Install Dependencies**
   Run the following command to fetch the required packages:
   ```powershell
   flutter pub get
   ```

2. **Check for Devices**
   Ensure you have a device or emulator connected:
   ```powershell
   flutter devices
   ```

3. **Run the App**
   Start the application in debug mode:
   ```powershell
   flutter run
   ```

// turbo
4. **Run pub get automatically**
   ```powershell
   flutter pub get
   ```
